# Java Stock Portfolio

A Java-based stock portfolio application demonstrating object-oriented programming concepts.

## Features
- Represents stocks and their financial information
- Tracks stock holdings and share values
- Supports different types of investment accounts
- Uses Java classes and object-oriented design

## Technologies
- Java

## About
Developed as part of a computer science course to practice object-oriented programming in Java. The project uses multiple interacting classes to model stocks, financial data, and investment accounts.

Portions of the application were provided as starter code and extended as part of the project.
